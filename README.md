# EcoTrack

Aplicacio Angular per registrar la recollida de residus en plantes industrials (PWA + APK amb Capacitor).

## Demo web

https://as-ten-mu.vercel.app/

GitHub Pages (alternativa): https://nicolai16.github.io/IvanProjecteFinal/

## Desenvolupament local

```bash
npm install
npm start
```

## Build produccio

```bash
npm run build
```

## APK Android

```bash
npm run build
npx cap sync android
npx cap open android
```

A Android Studio: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
